# Fit/Gap-анализ цифрового аукциона Diamond Universe

## Промежуточное TO BE (запуск через 2 месяца)

### Список систем

| Система                                                                | Функциональность                                                                                                          | Комментарий                                                                                   |
| ---------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| ИС «Алмазы» (существующая, внутренняя, основной бизнес)                | Учёт камней, идентификация, планирование, ведомости (существующая). Отбор камней для цифрового аукциона (новая)           | Требуется настроить функцию отбора камней именно для цифрового аукциона.                      |
| ИС «Аукцион» (существующая, внутренняя, основной бизнес)               | Проведение офлайн-аукциона (существующая). Публикация данных для клиентов и проведение цифрового аукциона (новые)         | Требуется доработать для создания цифровых лотов и первого электронного аукциона.             |
| ИС «Логистика» (существующая, внутренняя, обеспечивающая)              | Перевозка камней по стране и за границу (существующая). Отправка в лабораторию через перевозчика и возврат в офис (новая) | Требуется настроить новый маршрут и правила подтверждения передачи камней.                    |
| ИС «Бухгалтерия» (существующая, внутренняя, обеспечивающая)            | Контракты, актирование и оплата услуг перевозчика (существующая). Актирование и оплата услуг лаборатории (новая)          | Требуется настроить учёт нового вида услуг - оцифровку камней.                                |
| ИС «Лаборатория» (новая, внешняя, обеспечивающая, у подрядчика)        | Оцифровка камней, подготовка описания, фото и материалов (новая)                                                          | Новая внешняя система. На первом этапе результаты передаются вручную в согласованном формате. |
| Облачный сервис публикации материалов (новый, внешний, обеспечивающий) | Размещение цифрового каталога и материалов по лотам для покупателей (новая)                                               | Временное решение для доступа покупателей к материалам до появления постоянного варианта.     |

### Список интеграций

| Интеграция                                        | Как будет реализована                             | Какие будут передаваться данные                                                                  |
| ------------------------------------------------- | ------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| ИС «Алмазы» → ИС «Логистика» (существующая)       | Автоматически                                     | Существующие данные для планирования перевозки; новое направление - «офис - лаборатория - офис». |
| ИС «Алмазы» → ИС «Аукцион» (новая)                | Вручную                                           | Новые данные: идентификатор камня, характеристики, статус отбора для цифрового лота.             |
| ИС «Лаборатория» → ИС «Аукцион» (новая)           | Вручную                                           | Новые данные: описание камня, цифровой паспорт, фото и материалы лота.                           |
| ИС «Лаборатория» → ИС «Бухгалтерия» (новая)       | Вручную                                           | Новые данные: сведения об услугах лаборатории для актирования и оплаты.                          |
| ИС «Аукцион» → Облачный сервис публикации (новая) | Вручную                                           | Новые данные: проверенные материалы лота для показа покупателям.                                 |
| ИС «Логистика» → ИС «Бухгалтерия» (существующая)  | Автоматически или в текущем реализованном формате | Существующие данные об услугах перевозчика; новые данные о перевозке в лабораторию и обратно.    |
| ИС «Аукцион» → ИС «Логистика» (новая)             | Вручную                                           | Новые данные: результат аукциона, сведения о победителе для доставки.                            |
| ИС «Аукцион» → ИС «Бухгалтерия» (новая)           | Вручную                                           | Новые данные: результат аукциона для оформления сделки.                                          |

### Список систем

| Система                                                                                        | Функциональность                                                                                                                   | Комментарий                                                                                                                          |
| ---------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| ИС «Алмазы» (существующая, внутренняя, основной бизнес)                                        | Учёт камней, идентификация, планирование, ведомости (существующая). Отбор камней для цифрового аукциона (доработанная)             | Функция отбора должна автоматически передавать данные в аукционный процесс.                                                          |
| ИС «Аукцион» (существующая, внутренняя, основной бизнес, доработанная)                         | Проведение аукциона, подготовка цифровых лотов, публикация данных для клиентов, фиксация результатов (существующие и доработанные) | Ручные операции подготовки и публикации лотов должны быть устранены.                                                                 |
| ИС «Логистика» (существующая, внутренняя, обеспечивающая, доработанная)                        | Перевозка камней, включая маршрут в лабораторию и доставку покупателю (существующая и доработанная)                                | Требуется автоматическое получение задания на перевозку из аукционного процесса.                                                     |
| ИС «Бухгалтерия» (существующая, внутренняя, обеспечивающая, доработанная)                      | Контракты, актирование и оплата услуг лаборатории и перевозчика (существующие и доработанные)                                      | Требуется автоматическое получение оснований для актирования и оплаты.                                                               |
| ИС «Лаборатория» (существующая, внешняя, обеспечивающая)                                       | Оцифровка камней, цифровой паспорт, фото и материалы (существующая)                                                                | Система остаётся внешней, способ взаимодействия становится автоматическим.                                                           |
| Сервис хранения и публикации цифровых материалов (новая или выбранная внешняя, обеспечивающая) | Хранение и публикация цифровых материалов по лотам, контролируемый доступ покупателей (новая)                                      | Может быть внутренним или внешним облачным решением при условии управляемого доступа, резервного копирования и переносимости данных. |
